# Random Dirt Drops

A configurable Fabric mod that makes selected blocks drop random items instead of their normal loot.

## Features

- Configure which blocks trigger random drops
- Optional "All Blocks Mode"
- Random enchanted items
- Random potions
- Random enchanted books
- Random suspicious stews
- Random fireworks
- Configurable excluded item list
- Server-side configuration
- Automatic config generation

## Configuration

After launching the game once, the mod creates:

```
config/randomdirtdrops/
```

Containing:

- `config.properties`
- `blocks.txt`
- `excluded_items.txt`
- `README.txt`
